<div align="center">
  
### Common Questions

English: Is this right?<br>
Spanish: Es este correcto?

English: Can you help me with this?<br>
Spanish: Me puede auidar con esto?

### Being Helpful

English: Can you speak slowly, please?<br>
Spanish: Puede hablar mas despacio, por favor?

English: Call me when you arrive.<br>
Spanish: Llamame cuando llegues.
